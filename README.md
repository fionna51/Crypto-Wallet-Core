# Crypto-Wallet-Core

![License](https://img.shields.io/badge/license-Apache--2.0-blue.svg) ![Stack](https://img.shields.io/badge/lang-Java-informational.svg)

> Core cryptography library for HD wallet key derivation and signing.

## Overview
Core implementation lives under `legacy-api-java/TransactionManager.java` alongside modular configuration and telemetry utilities.

## Quick Start
1. Review defaults inside `config/defaults.json`.
2. Run the unit suite under `tests/` before deploying.
